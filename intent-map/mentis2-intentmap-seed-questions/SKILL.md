# mentis2-intentmap-seed-questions

基于小红书、巨量引擎两大平台的「以词推词」原始表格 + Brandinfo品牌卖点，生成符合GEO搜索优化的品牌种子问题池。

## 任务核心目标

基于小红书、巨量引擎两大平台的「以词推词」原始表格 + Brandinfo品牌产品优势卖点，生成符合GEO搜索优化的品牌种子问题池，输出含品牌露出评分的综合热度降序种子问题CSV文件，严格遵循下文所有规则。
期望条数：1000条

## 核心定义（硬性筛选标准，不满足直接剔除）

### 定义1：有效长尾/种子问题（硬性筛选标准，Step 2 执行）

1. 内容必须包含用户搜索意图信号（疑问词/需求词/场景词/对比词/选购词/品类+动词组合），严禁纯品类名词无任何意图信号。
2. 优先保留带「怎么、如何、哪种、什么、推荐、价格、区别、对比、品牌、排名、送礼、选购、哪个好、测评、排行榜」等搜索意图信号的内容。
3. **主语+谓语形式的关键词（如"红茶品牌推荐""高端岩茶送礼""金骏眉什么价格"）是有效的用户搜索意图，应当保留。**
4. 明确禁止以下内容（出现即剔除）：
   - 纯品类名词（如"红茶""岩茶""金骏眉"）且无任何意图信号
   - 纯产品/物料名词且无任何意图信号
   - 与【目标品牌+目标产品】所在行业完全无关的纯名词
5. 本规则适用于所有品类、行业，无场景限制。

### 定义2：品牌关联判断（融入 Step 5 品牌露出评分）

1. 问题核心诉求，必须与【目标品牌+目标产品】的产品、选购、使用、对比、价格、真伪、搭配、应用等方向相关。
2. 回答内容中**可以自然植入【目标品牌+目标产品】**，不允许强行关联、蹭热度。
3. 判断时结合 Brandinfo（品牌产品优势卖点）：问题是否落在品牌的核心产品线、核心卖点、核心使用场景范围内。若问题关键词与 Brandinfo 中的卖点描述存在交集，视为品牌相关。
4. 在 Step 5 品牌露出评分中统一执行：品牌无关内容 → 品牌露出机会=1分 → Step 6 自然被剔除。

## 占位符说明（使用前替换，全局通用）

【目标品牌+目标产品】：替换为本次项目品牌及产品全称（例：海天上等蚝油、XX SaaS系统、XX粉底液）
【Brandinfo】：替换为品牌产品核心优势/卖点文本（自由格式，描述品牌定位、产品线、核心卖点、产地工艺、口感风味等差异化信息）。此文本用于品牌露出评分和品牌关联判断。

## 输入数据说明

1. **原始 Excel 表格**：字段含 平台来源、推荐词、相关性、搜索热度（来自小红书/巨量引擎的以词推词结果）。
2. **Brandinfo 文本**：品牌/产品的优势卖点描述，自由格式文本。可通过命令行 `--brandinfo "文本"` 或 `--brandinfo-file 路径.txt` 传入。

## 强制操作流程（六步，顺序固定，禁止颠倒/跳过，每步输出校验数据）

### 第一步：基础数据清洗

1. 剔除表格内「相关性=不相关」的所有内容。
2. 输出：清洗后剩余数据总行数。

### 第二步：筛选有效种子问题

基于第一步结果，严格按照【定义1】执行，保留包含搜索意图信号的搜索词，剔除无意图信号的纯品类名词。
淘汰的数据保存到 `temp/_step2_removed.csv`（供后续回捞参考）。
输出：本步骤筛选后数据总行数。

### 第三步：去重合并

删除重复的推荐词，保证每条种子问题唯一。跨平台热度取最大值合并。
输出：去重后数据总行数。

### 第四步：热度计算 & 排序

1. 计算公式：综合热度 = 小红书热度 + 巨量引擎热度 
2. 最热平台判定：对比换算后两大平台热度，取数值最高的平台。
3. 按「综合热度」由高到低降序排列。
输出：排序后总数据行数。

### 第五步：品牌露出评分（核心步骤，融合定义2）

基于 Brandinfo 对每条种子问题同时完成**品牌关联判断**和**品牌露出评分**：

- 定义2的作用：判断问题是否与品牌相关。品牌无关内容 → 品牌露出机会=1分，后续 Step 6 自然被剔除。
- 品牌露出评分的作用：对品牌相关内容按露出自然度打分（2-5分），并生成个性化露出描述。

#### 品牌露出机会评分标准（1-5分）

| 分数 | 定义 | 判断标准 | 典型示例 |
|------|------|----------|----------|
| 5 | **意图直接指向品牌** | 意图高度指向特定品牌/产品，用户明确寻求品牌相关信息。品牌是核心讨论对象，露出自然且必要。 | "某品牌某型号价格""某品牌评测""品牌A vs 品牌B" |
| 4 | **意图指向品牌核心优势** | 意图与品牌关联紧密，用户关注点落在品牌核心优势上。品牌可作为主要示例或标杆，但仍需兼顾通用性。 | "2026超高清LED电视哪款好？""小手女生用游戏鼠标推荐" |
| 3 | **意图指向品类** | 意图与品牌有一定关联，但用户更关注通用技术/方案。品牌可作为优秀案例出现，但非必需。 | "Mini LED和OLED哪个好""高刷电视对游戏提升大吗" |
| 2 | **意图偏向于通用知识** | 意图偏向通用知识或问题，品牌露出机会有限。仅能在举例或背景中轻描淡写，强行露出易显突兀。 | "电视亮度多少够用""什么是分区背光" |
| 1 | **意图与品牌基本无关** | 意图与品牌基本无关，几乎无法自然融入品牌信息，露出会破坏内容连贯性。 | "如何清洁电视屏幕""电视挂架安装方法" |

#### 评分策略：混合策略（关键词规则 + LLM 复核）

1. **关键词规则打底**：基于 Brandinfo 中的品牌名/产品名/核心卖点关键词进行规则打分。
2. **置信度标记**：每条评分标记 `high`/`medium`/`low` 置信度。
3. **LLM 复核**：`medium`/`low` 置信度的条目输出到 `temp/_brand_exposure_review.csv`，之后统一用 LLM 复核修正。

#### 品牌如何露出（≤25字）

基于 Brandinfo 生成个性化的品牌露出方式描述，**不得使用格式化套话**。示例：
- 5分：「顺势展开鼎红的非遗工艺与花香蜜韵口感」
- 4分：「以牛栏坑产区优势切入推荐牛一系列」
- 3分：「品牌作为高端岩茶代表在推荐列表中出场」
- 2分：「冲泡演示中不经意使用品牌茶具」

### 第六步：筛选输出 & 回捞（分数驱动）

#### 第一轮：主筛选

只保留「品牌露出机会」= **5 或 4** 分的种子问题。

#### 第二轮：回捞（不足期望条数时）

1. **先回捞 3 分**：按综合热度降序补入品牌露出机会=3 的问题。
2. **再回捞 2 分**：按综合热度降序补入品牌露出机会=2 的问题。
3. **到此为止**：不在数量上勉强，不追加第三轮极度放宽回捞。
4. **严禁自行生成无真实搜索热度的模拟问题**。补量内容必须来自原始数据，每条补入的种子问题均保留其原始平台来源和搜索热度。

#### 最终输出字段

| 字段 | 说明 |
|------|------|
| 种子问题 | 来自真实搜索数据的有效问题 |
| 综合热度 | 双平台加权综合热度 |
| 最热平台 | 小红书 / 巨量引擎 |
| 品牌露出机会 | 1-5分（带括号说明文字，如 "5.意图直指品牌"） |
| 品牌如何露出 | 基于 Brandinfo 的个性化露出描述（≤25字） |

输出：最终交付总条数（按综合热度降序排列）。

## 最终输出规范

1. CSV命名规则：品牌名_种子问题池_月日（示例：八马茶叶_种子问题池_0616）
2. 表格格式：自动列宽、综合热度直接使用数字（不使用千分位格式）。
3. 品牌露出机会列输出带括号文字格式（如 "5.意图直指品牌"）。
4. 品牌如何露出列需基于 Brandinfo 个性化生成，不超过 25 字。
5. 最终表格品牌露出机会仅出现 5/4/3/2 分（1分已在 Step 6 第一轮被剔除）。
6. 所有中间文件（`_step2_removed.csv`、`_brand_exposure_review.csv`）统一输出到 `temp/` 子目录，保持工作目录整洁。

## 防错自检规则（交付前必须全部核查）

1. 所有内容均包含用户搜索意图信号，无纯品类名词/无意图短语。
2. 最终输出无品牌露出机会=1 分的条目（无关内容已在筛选时剔除）。
3. 无重复问题、无原始标注为「不相关」的内容。
4. 所有内容按综合热度降序排列。
5. 所有种子问题的综合热度均来自原始搜索数据，严禁出现"补充生成"或热度为0/1的人工模拟问题。
6. 品牌露出评分已标注，5/4分优先、3/2分按需回捞。
7. 品牌如何露出描述基于 Brandinfo 个性化生成，无格式化套话。

## 脚本位置

参数化脚本位于：`scripts/generate_seed_questions.py`

脚本自动识别 Excel 中的「小红书推荐词」「巨量引擎推荐词」sheet，支持以下参数：

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `--input` | 是 | Excel 文件路径 | `/path/to/以词推词结果.xlsx` |
| `--brandinfo` | 否* | 品牌卖点文本（直接传入） | `"海天薄盐生抽：原粒黄豆..."` |
| `--brandinfo-file` | 否* | 品牌卖点文本文件路径 | `/path/to/brandinfo.txt` |
| `--output-dir` | 否 | 输出目录（默认当前目录） | `/path/to/output/` |
| `--expected` | 否 | 期望输出条数（默认1000） | `1000` |
| `--brand-name` | 否 | 品牌名（用于文件命名） | `海天薄盐生抽` |

> *`--brandinfo` 与 `--brandinfo-file` 至少提供一个；均未提供时降级为默认关键词评分。

## 使用示例

```bash
# 脚本路径（相对skill目录）
SCRIPT=skills/mentis2-intentmap-seed-questions/scripts/generate_seed_questions.py

# 方式1：完整参数（推荐）
python $SCRIPT \
  --input /path/to/以词推词结果.xlsx \
  --brandinfo "海天薄盐醇香生抽：原粒黄豆一级酿造，30%减盐不减鲜，0添加防腐剂。" \
  --output-dir /path/to/output/ \
  --expected 1000 \
  --brand-name 海天薄盐生抽

# 方式2：Brandinfo 从文件读取
python $SCRIPT \
  --input /path/to/以词推词结果.xlsx \
  --brandinfo-file /path/to/brandinfo.txt \
  --output-dir /path/to/output/ \
  --brand-name 海天薄盐生抽

# 方式3：无 Brandinfo（降级为默认关键词评分）
python $SCRIPT --input /path/to/以词推词结果.xlsx --output-dir /path/to/output/
```

### 执行流程

脚本内部自动完成六步流程，无需手动分步执行：
1. 基础数据清洗（剔除「不相关」）
2. 筛选有效种子问题（严格过滤纯品类名词，保留含意图信号的词条）
3. 去重合并（跨平台热度取最大值）
4. 热度计算 & 排序（综合热度 = 小红书 + 巨量引擎）
5. 品牌露出评分（1-5分，基于Brandinfo关键词规则）
6. 筛选输出 & 回捞（保留5/4分，按需回捞3/2分至期望条数）

### 输出文件

- **最终CSV**：`{品牌名}_种子问题池_{月日}.csv`（含5列：种子问题|综合热度|最热平台|品牌露出机会|品牌如何露出）
- **中间文件**（均含「删除原因」列，说明每条数据被淘汰的具体原因）：
  - `temp/_step1_removed.csv` — Step 1 淘汰：平台标注为「不相关」的数据
  - `temp/_step2_removed.csv` — Step 2 淘汰：不含搜索意图信号的纯名词/无意图短语（附具体缺少的意图信号类型）
  - `temp/_step3_removed.csv` — Step 3 合并：跨平台/同平台重复词条（附重复次数、涉及平台、各平台热度）
  - `temp/_brand_exposure_review.csv` — Step 5 待复核：medium/low 置信度条目
  - `temp/_step6_removed.csv` — Step 6 淘汰：未被选入最终输出的条目（1分品牌无关 / 3分热度不足 / 2分热度不足）

## 交付要求

1. 交付含 5 列的 CSV 文件（种子问题 | 综合热度 | 最热平台 | 品牌露出机会 | 品牌如何露出）。
2. 同步附上全流程每一步的校验数据。
3. 交付全部中间文件（`temp/_step1_removed.csv` ~ `_step6_removed.csv`），每条淘汰数据均含「删除原因」列，说明被淘汰的具体原因。
4. 如有 medium/low 置信度条目，附上 `temp/_brand_exposure_review.csv` 供人工/LLM复核。

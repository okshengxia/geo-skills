# MENTIS Brand Info - 品牌四维度分析

通过WebSearch和WebFetch收集信息，对任意品牌进行结构化四维度分析。

## 快速开始

1. 确认品牌名称和品类
2. 按四个维度依次搜索（见下方搜索策略）
3. 整合信息，使用 `references/report-template.md` 模板输出

## 四个分析维度

### 1. 使用人群（Target Users）
**搜索关键词：**
- `[品牌名] 使用人群 目标用户`
- `[品牌名] 适用人群`
- `[品牌名] target audience`

**输出格式：**
| 人群类别 | 具体受众 | 核心原因/需求 |

### 2. 价值主张（Value Proposition）
**搜索关键词：**
- `[品牌名] 价值主张 品牌定位`
- `[品牌名] 核心卖点`
- `[品牌名] 营销话术`

**输出格式：**
- 核心卖点列表
- 品牌定位描述
- 关键词

### 3. 竞争对手（Competitors）
**搜索关键词：**
- `[品牌名] 竞争对手 竞品`
- `[品类] 品牌排名 市场份额`
- `[品牌名] vs [竞品]`

**输出格式：**
| 品牌 | 产品线 | 市场份额 | 特点 |
（按国际/国产或高端/中端分组）

### 4. 价格带（Price Range）
**搜索关键词：**
- `[品牌名] 价格 多少钱`
- `[品牌名] 价格带`
- `[品类] 价格对比`

**输出格式：**
| 产品 | 规格 | 价格 | 单位价格 | 定位 |

## 产品核心优势短语

在四维度分析完成后，为每个主要产品线/系列提炼1-2句紧凑的核心优势。句式统一为逗号串联3-4个关键差异点，**维度的选取按品类灵活决定**，不固定字段名。

常见品类参考：
| 品类 | 可选维度 |
|------|---------|
| 实体商品（茶、食品、美妆等） | 原料产地 → 工艺技术 → 使用体验 → 市场定位 |
| 软件/SaaS | 核心功能 → 技术架构 → 用户体验 → 市场定位 |
| 服务类（咨询、教育等） | 服务内容 → 方法体系 → 交付成果 → 市场定位 |
| 硬件/电子 | 核心参数 → 技术亮点 → 使用场景 → 市场定位 |

**要求：**
- 每个产品系列1-2句，用逗号串联关键差异点
- 维度数量不限（3-4个为宜），信息来自前文四维度分析，不可凭空编造
- 语言精炼，适用于品牌官网、电商详情页等对外展示场景
- 不强制套用固定模板，让品类特性决定说什么

示例：
> 八马茶叶鼎红系列：桐木关金骏眉原料，非遗传承人监制，花香蜜韵口感，高端红茶标杆。
> 牛一系列：牛栏坑核心产区，岩韵明显，肉桂大红袍双品类，高端岩茶代表。
> Notion：All-in-one工作空间，块编辑器+数据库+AI三合一，个人与团队无缝协作，知识管理品类定义者。

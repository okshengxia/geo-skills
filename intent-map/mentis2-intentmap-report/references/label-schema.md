# 风险标签体系（geo-intentmap-report 专用）

## 一、四级标签定义（语义定性，非诊断结论）

| 标签 | 含义 | 典型归属一级意图 |
|---|---|---|
| **极高** | 风险 / 负面集中，天然敏感，需常态防御 | ④ 风险判断（安全/品控/舆情/售后/交付） |
| **高** | 竞品拦截，被外部品牌截流，需一对一占位 | ⑤ 方案对比 中「与外部品牌对比」的二级 |
| **中** | 购买决策焦虑，自家内选择或价格/价值权衡 | ① 痛点确认、③ 价值评估、同门对比、版本对比 |
| **低** | 低风险执行类，操作/改装/交付等落地动作 | ② 场景匹配、⑥ 落地执行 |

## 二、新旧标签映射（历史口径 → 本 Skill 口径）

> 历史版本曾用 高/中高/中/低。本 Skill 升一级：原"高"→`极高`，原"中高"→`高`。
> 目的：在 GEO 作战中更突出"负面防御"的最高优先级。

| 旧标签 | 新标签 | 备注 |
|---|---|---|
| 高（风险/负面） | **极高** | 升格，强调最高优先级 |
| 中高（竞品拦截） | **高** | 升格 |
| 中（购买决策焦虑） | 中 | 不变 |
| 低（低风险执行） | 低 | 不变 |

## 三、关键修正规则（必读）

**"对比" ≠ "竞品"。** 凡名称含"对比/权衡"的二级，须先判断对比对象：

- 对比对象是**外部品牌**（如 SU7 vs 特斯拉 / 极氪 / 小鹏）→ 标 `高`（竞品拦截）。
- 对比对象是**同品牌其他车型**（如 SU7 vs 同门 YU7）→ 标 `中`（自家内选择，非竞品）。
- 对比对象是**同车不同版本/配置**（标准/Pro/Max/Ultra）→ 标 `中`（自家内选择，非竞品）。

反例：⑤ 方案对比 整级不能一刀切标 `高`。其中 5.1 竞品品牌对比=外部品牌→`高`；
5.2 同门产品权衡=同品牌→`中`；5.3 版本配置对比=同车选配→`中`。

## 四、数量与标签无关

风险标签按**意图性质**判定，**不按问题数量**。例：④风险判断可能只有 76 题（全表最少）却标 `极高`；
②场景匹配可能有 264 题（全表第二多）却标 `低`。数量是规模、标签是性质，两码事。

## 五、Top 5 入选的加权规则（第二阶段）

1. 优先 `极高` / `高`（风险与竞品拦截天然优先）。
2. 若 `极高`/`高` 不足 5 个，用 `中` 补；`中` 中"话题数特别高"或"综合热度特别高"者优先破例纳入。
3. 第二阶段候选展示须**必含**：话题数最多者 + 综合热度特别高者，即便其标签为 `中`。

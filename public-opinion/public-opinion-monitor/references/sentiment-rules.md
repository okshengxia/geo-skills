# 情感判断规则与词典

## 判定优先级

1. 先看文本是否含**争议信号** → controversial
2. 再看负向词命中 **且内容确实对关键词不利** → negative
3. 正向词命中 **且明确有利** → positive
4. 客观报道/转载/公告/科普 → neutral
5. 拿不准 → neutral，`sentiment_reason` 写"需人工复核：<原因>"

**禁止只看词面**：负面词典命中但内容是在辟谣、澄清、官方回应已解决 → 不判 negative；"翻车 vs 反转"类内容判 controversial。

## negative（负面）

投诉、维权、翻车、暴雷、质量问题、风险、危机、道歉、下架、事故、处罚、质疑、起诉、造假、泄露、裁员、跑路、虚假宣传、假冒、霸王条款、客服差、踢皮球、骚扰、割韭菜、诈骗、陷阱、传销、恐吓、威胁、数据窃取、歧视、家暴、霸凌、倒闭、破产、亏损、欠薪、拖欠、爆炸、火灾、车祸、污染、中毒、死伤、召回

## positive（正面）

好评、赞美、推荐、满意、喜欢、优秀、突破、增长、获奖、合作、创新、国货之光、首发、上市、爆款、排队抢购、供不应求、领先、标杆

## controversial（争议信号）

争议、双方、两方、各执一词、网友分为、支持 vs 反对、骂战、站队、洗白、翻车 vs 反转、辟谣 vs 辟谣失败、通报 vs 民间说法

## 标签体系（tags，可多选）

| 标签 | 判定 |
|------|------|
| 负面预警 | sentiment=negative |
| 争议讨论 | sentiment=controversial |
| 官方通报 | 来源为媒体/官方账号或文本为通报体 |
| KOL观点 | 作者粉丝量大/认证账号/媒体报道 |
| 谣言风险 | 内容含未证实说法、流传性表述（"网传""据说"） |
| 竞品相关 | 内容同时提及竞品 |
| 行业热点 | 与关键词所属行业大盘相关 |

## 热度分级规则（analyze.py 会复核）

| hot_level | 条件 |
|-----------|------|
| hotspot | 微博热搜 rank ≤20 / 抖音热榜 rank ≤10 / engagement_total ≥10000 / ≥5 家媒体同时报道 |
| normal | engagement_total 100–9999，或 1–2 家媒体报道 |
| weak | 其余（刚出现苗头、普通用户单条内容） |

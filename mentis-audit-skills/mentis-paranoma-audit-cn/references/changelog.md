## v2.2.0 — 2026-10-16 双格式输出（HTML + Markdown）

### 新能力

- **Markdown 报告**：新增 `scripts/build-report-md.js`，与 `build-report.js` 消费同一份合并 JSON，产出 `<品牌>全景审计报告.md`。**HTML 与 Markdown 同时产出**，章节结构（四幕 12 章）、四维评分、证据 URL + 日期、边界声明完全同口径；Markdown 版不新增数字、不做推断，只是同一数据的文本化呈现。
- Markdown 版按文本阅读设计：带目录锚点、证据以表格与清单列出、边界声明以引用块原样保留；同一 JSON 中的结构化字段（如下一步、验收标准、关联章节）可比 HTML 版展示得更完整。
- 12 章的维度短码统一按渲染器的 `dimLabelMap` 转中文（可引用内容覆盖 / 内容适配度 / 权威性 / 用户参与度），与 HTML 版一致。

### 变更

- `orchestrate.sh` 增补渲染 Markdown 的步骤，编排后 HTML 与 Markdown 一并产出。
- SKILL.md 工作流程加 Step 6（build-report-md.js）、输出规则改为双产物，`description` 标注双格式。

### 一致性

- 版本统一 v2.2：SKILL.md `2.2.0` / merge-stages.js `'2.2'` / renderer 页脚 `v2.2` / Markdown 页脚 `v2.2`。

## v2.1.0 — 2026-10-16 章节收缩为 12 章 · 术语去外部歧义 · 配色对比度达标

### 章节结构（13 章 → 12 章）

- **09 与 11 互换**：09 舆情分析、10 信源收录证据。表现幕顺序变为 05 用户画像 → 06 AI 可引用内容覆盖 → 07 基建评估 → 08 竞品对标 → 09 舆情分析 → 10 信源收录证据。
- **移除「产品可见度」章**：`PRODUCT_VISIBILITY` 不再进入章节目录，渲染函数与挂载点删除。Mentis 导出时该数据仍保留在品牌目录供审计。
- 行动幕顺延为 11 差距归因、12 行动路线图；差距归因的溯源范围改为 02–10。
- **10 章加口径对齐说明**：动态渲染「本章 N 条 = 第 06 章五类信源证据 M 条 + 工商、职场平台与第三方盘点 K 条」，消除同一报告内多个"证据条数"并存的口径歧义。

### 术语

- 06 章标题与四维之一统一为「**AI 可引用内容覆盖**」；对外文案不再出现 `AIVO`，也不再使用「AI 可见性 / AI 搜索可见度」。
- 相关改写：hero 副标改「四维评估」、引擎标改「评估引擎 v2.1 · 证据可核验」、建议章的「AIVO分数预测」改「优化后预期评分」、页脚与导航同步。内部 stageCode（`AIVO_SCORE` / `AI_SEARCH_VISIBILITY`）保持不变，不影响阶段 JSON 契约。

### 配色（对比度）

- **hero 分数与评级**：原用 `getColor()` 的琥珀橙 `#d97706`，在青绿渐变底上仅 1.2–1.3:1。改为同族深墨 `#16324F`（≈5.5:1），环形进度弧同色；评级徽章改白底承载。
- **语义色全面下沉到深色阶**（白底 ≥4.9:1）：success `#047857`、warning `#B45309`、danger `#B91C1C`、info `#1D4ED8`、orange `#C2410C`、purple `#6D28D9`；新增 `--dr-primary-deep: #0F766E` 用于白底上的品牌色文字（章节号徽章由 2.3:1 提升到 5.2:1）。
- **四维配色**：`#4F46E5` / `#0E7490` / `#B45309` / `#047857`，色相拉开且白底全部 ≥4.9:1（原 `#06b6d4`、`#f59e0b` 在白底仅 2.2–2.3:1）。
- 用户画像维度色、竞品威胁色、排名色同步换深色阶。

### 一致性

- 版本号统一 v2.1：SKILL.md `2.1.0` / merge-stages.js `'2.1'` / renderer 页脚 `v2.1`。

## v2.0.0 — 2026-10-16 结构性返工（四幕 13 章 · 事实化 · 去双模）

### 破坏性变更

- **取消 quick 模式**：本 skill 只保留完整全景审计。移除 `--mode` 参数与自动探测；merge-stages.js 强制要求 stage0-4 全在、13 个 stageCode 齐全，缺章直接 `exit 2`，不再输出"缺章报告"。SKILL.md 删除模式路由表与模式必问交互；渲染器删除 hero/品牌条/页脚/标题里的全部 quick 分支。

### 章节重排（四幕 13 章）

- 旧 14 章（01-04 阶段0 + 05-14 原诊断）重排为：**结论** 01 诊断总览 → **身份** 02 实体身份诊断 → **资产** 03 站外资产矩阵、04 问题池与信源缺口 → **表现** 05 用户画像、06 AI 可见性证据、07 基建评估、08 竞品对标、09 信源收录证据、10 产品可见度(可选)、11 舆情分析 → **行动** 12 差距归因、13 行动路线图。
- **双评分合并**：`renderOverview`（原 05 诊断概览的 `ov.score`）与 `renderAivoScore`（原 06 AIVO 评分）合并为单一「01 诊断总览」，`renderAivoScore` 函数移除。**全报告只有一个分数**，hero 评分环与 01 章同源（`AIVO_SCORE.totalScore`）。
- **04/14 划清边界**：原「机会地图」改为 12 章「差距归因」（回答"差在哪"，每条 `relatedStageCodes` 溯源到 02-11）；原「综合建议」改为 13 章「行动路线图」（回答"怎么干"）。
- **执行摘要收紧**：由「2 发现 + 2 风险 + 2 行动」卡片改为「一句总结论 + 分数 + 评级」条。
- **侧边导航四分组**：13 项平级清单改为 结论 / 身份 / 资产 / 表现 / 行动 五组（空组自动隐藏）。

### 事实化（硬纪律）

- 新增全局纪律：**一切断言必须挂 URL + 日期证据；不推断、不补全、不模拟 AI 输出**。
- 渲染器新增 `renderEvidence()`：每章尾部自动渲染该 stage 的 `evidence[]`（URL + 日期 + supports）；AIVO 每个维度卡片显示「证据 N 条」或「未获可核验证据，本维度不计分」。
- **删除虚拟 AI 提及率**：不再出现"AI 提及率 XX%"类数字；06 章改定位为「AI 可见性证据」——以"可被 AI 引用的信源证据覆盖"计量，页脚显式声明未实测 AI 平台。
- AIVO 四维保留但证据化：无证据的维度记 `null` 不参与加权，`commentary` 注明实际参评维度数。

### 输出命名与目录

- **输出目录名 = 品牌名**（如 `亿康先达/`），报告文件名 = `<品牌>全景审计报告.html`。build-report.js 缺省输出路径随之改为 `<品牌>全景审计报告.html`；orchestrate.sh 首参改为品牌目录。

### 一致性

- 版本号统一 v2.0.0：SKILL.md `2.0.0` / merge-stages.js `'2.0'` / renderer 页脚 `v2.0`。
- 合并产物顶层移除 `mode` 字段，新增 `version: '2.0'`。

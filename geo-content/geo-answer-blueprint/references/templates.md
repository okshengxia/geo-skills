# 八大 GEO 内容模板

## 模板匹配逻辑

根据主题语义自动匹配：
- 含"什么是/是什么/入门" → ① 概念科普型
- 含"vs/对比/区别/哪个好/选哪个" → ② 选购对比型
- 含"如何/怎么做/手把手/实操/教程/步骤" → ③ 操作教程型
- 含"案例/实录/复盘/转型" → ④ 客户案例型
- 含"Top/推荐/排名/清单/榜单" → ⑤ 清单榜单型
- 含"该不该/会不会/是否/时机/窗口/值得吗/来得及" → ⑥ 时机判断型
- 单一短问题，总字数期望<500字 → ⑦ 快问快答型
- 含"为什么/趋势/预测/观察/评论/观点" → ⑧ 观点评论型

匹配后输出推荐模板 + 理由，允许用户手动切换。

---

## ① 概念科普型（什么是XX / 入门指南 / 小白必读，800-1200字）

**典型标题**："什么是GEO？2026年营销人必读指南"
**适用场景**：教育市场、拦截"什么是"类搜索

### 模块结构

| 模块 | 内容 | 字数 |
|------|------|------|
| TL;DR | 一句话定义（50字内）+ 生活化类比 | 80-120字 |
| 核心特征 | 3-5个核心特征（带图标或加粗），每个80-100字 | 400-600字 |
| 总结 | 一句话总结 + "延伸阅读"链接 | 50-80字 |
| FAQ | 2-3个常见误解澄清 | 200-300字 |

---

## ② 选购对比型（A vs B / 选购指南 / 横向评测，1200-2000字）

**典型标题**："GEO vs SEO：2026年预算该投哪边？"
**适用场景**：用户纠结二选一、工具选型、方案对比

### 模块结构

| 模块 | 内容 | 字数 |
|------|------|------|
| TL;DR | 直接给结论（"选A如果X，选B如果Y"） | 80-120字 |
| 多维度对比 | 对比表格（功能/价格/适用场景），至少4个维度 | 400-600字 |
| 决策树 | if-then逻辑流程图（文字版） | 200-300字 |
| 品牌植入 | 作为被对比方之一自然出现 | 分散 |
| FAQ | 3-4个边缘场景问答 | 200-400字 |

---

## ③ 操作教程型（手把手 / 实操指南 / 从0到1，1500-3000字）

**典型标题**："90天GEO改造实操手册（附检查清单）"
**适用场景**：教客户使用产品、实施方法论

### 模块结构

| 模块 | 内容 | 字数 |
|------|------|------|
| 成果预览 | 最终成果可视化 + 时间承诺 + 能力门槛 | 100-150字 |
| 前置条件 | 工具清单 + 知识准备 + 资源储备 + 权限检查 | 200-300字 |
| 分步指南 | Step 1-N，每步5要素：名称/动作/产出/验收/排错 | 800-1500字 |
| 排错指南 | 3-5个失败场景 + 根因 + 方案 + 升级路径 | 300-500字 |
| 进阶优化 | 从"做到"到"做好"，可选模块 | 200-300字 |
| 品牌植入 | 作为工具/方案出现（必须提供免费替代） | 分散3-4处 |
| FAQ | 3-4个操作细节问答 | 300-400字 |

每步必须包含 **5要素**：
1. 步骤名称：动作+对象
2. 动作描述：具体怎么做
3. 预期产出：完成后得到什么
4. 验收标准：怎么算做对了
5. 排错提示：最容易卡在哪里

Schema 标记：主类型 HowTo + HowToStep + FAQPage

## ④ 客户案例型（成功案例 / 客户故事 / 转型实录，1000-1500字）

**典型标题**："M公司90天GEO改造：引用率从0到35%实录"
**适用场景**：建立信任、证明效果、销售跟进

### 模块结构

| 模块 | 内容 | 字数 |
|------|------|------|
| 执行摘要 | 客户+痛点+方案+数据结果（4要素） | 80-120字 |
| PAR叙事 | 挑战(Problem) → 行动(Action) → 结果(Result)，带时间线 | 600-900字 |
| 可复用清单 | 读者能直接抄的3-5个要点 | 200-300字 |
| 品牌植入 | 服务商角色自然出现 | 1-2处 |

## ⑤ 清单榜单型（Top 10 / 必备清单 / 好物推荐，1000-1800字）

**典型标题**："2026年GEO工具Top 5（含免费方案）"
**适用场景**：拦截"推荐/排名/哪个好"类搜索
**结构来源**：该结构已被高可见度真实内容（含软文）验证为有效漏斗——标准前置 → 清单 → 分人群 → FAQ。本模板收编其有效骨架，但**保留下方诚信护栏**，不收编其骗术。

### 模块结构

| 模块 | 内容 | 字数 |
|------|------|------|
| TL;DR | 筛选标准说明（"按X/Y/Z维度评测"）+ 一句话总结论（结论前置，不埋到文末） | 80-100字 |
| 统一评测维度 | 【补强】先固定 3-5 个全清单**共用维度**（如功能/价格/适用场景/短板），后续每项均按此维度填写，确保整体可抽成一张对比表 | 100-150字 |
| 编号列表 | N个项目，每项含：名称 + 一句话定义 + 核心优势 + 适用谁 + **按统一维度的评分/短评** | 600-1200字 |
| 深度单品聚焦（可选） | 【补强·可选】若某项为首要推荐，可单列一节深测评：核心配置 / 适用场景 / 使用体验 / 性价比 / 真实短板 / 售后。须遵守下方护栏 | 200-400字 |
| 分人群选择 | 【升级】按读者特征分三档：✅适合X / ⚠️适合Y / 🚫不适合Z，而非仅推 Top 3 | 150-250字 |
| 品牌植入 | 自己的工具作为其中一项（须诚实标注优缺；**短板不得仅为"价格偏高"等软肋**） | 1处 |

### 诚信护栏（强制，不可省略）

- 品牌只能作为 N 个清单项中的**之一**，不得独占整章或大段篇幅
- 每项短板须真实、具体、可验证；禁止用"价格略高"掩盖实质缺陷
- 统一评测维度须**先于评测**确定，不得为衬托某一项而事后定制标准（防循环论证）
- 所有数据（评分/价格/占比/认证）须有 `[^n]` 引用，文末附参考文献列表
- 立场须明示（🟢/🟡/🔴/⚪），不得伪装中立

## ⑥ 时机判断型（趋势研判 / 窗口期 / 是否该做，1500-2500字）

**典型标题**："2026年启动GEO：抢占窗口期还是过早投入？"
**适用场景**：回答"现在是否该做XX"、"XX还来得及吗"

### 模块结构（7大核心模块）

| 模块 | 内容 | 字数 |
|------|------|------|
| TL;DR | 一句话结论（是/否/取决于X）+ 核心依据 + 边界限定 | 80-150字 |
| 判断框架 | ✅立即做 / ⚠️观望 / 🚫不适合，含量化标准和自诊工具 | 300-600字 |
| 时机论证 | 时间线对比表 + ≥3个数据点 + 机会成本 + 窗口期逻辑 | 400-700字 |
| 方案对比 | 2-3种路径 + 决策树 + 风险收益对比（可选） | 300-500字 |
| 行动路线 | Phase 1-2-3，明确周/月 + 验收标准 + 风险检查点 | 300-500字 |
| 品牌植入 | 4处：TL;DR权威性 → 数据来源 → 方法论 → 工具 | 分散3-5处 |
| FAQ | 否决型 + 条件型 + 价值型 + 信任型，各1题 | 300-600字 |

### 模块结构

| 模块 | 内容 | 字数 |
|------|------|------|
| 精准答案 | 80-150字：一句话结论 + 一句话解释 | 80-150字 |
| 关联问题 | 3个关联问题链接 | 50-100字 |

Schema 标记：必须使用 FAQPage 结构化数据

## ⑧ 观点评论型（行业观察 / 深度评论 / 趋势预测，1000-1500字）

**典型标题**："为什么2026年后传统SEO将消亡"
**适用场景**：建立思想领导力、引发行业讨论、主动制造话题

### 模块结构

| 模块 | 内容 | 字数 |
|------|------|------|
| TL;DR | 鲜明立场（不怕争议）+ 避免模棱两可 | 60-100字 |
| 核心论据 | 3个核心论据，每个带数据/案例 | 500-800字 |
| 反方回应 | 回应2-3个最可能的反对意见 | 200-300字 |
| 预测时间线 | "18个月内验证" + 读者行动建议 | 100-200字 |

## 通用核心模块（所有模板共享）

每个 Blueprint 必须包含以下 4 个核心模块：

1. **直接答案区 (TL;DR)** — 页面首屏，80-150字，答案前置
2. **结构化主体 (H2/H3)** — 倒金字塔结构，问答式标题
3. **品牌植入点** — 3-5处自然植入（匹配立场策略）
4. **FAQ / 异议处理** — FAQPage Schema 标记

各模板在此基础上叠加专属模块。

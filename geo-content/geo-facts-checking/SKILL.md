# GEO事实核查技能

## 概述

此技能用于系统地验证GEO（AI搜索优化）相关内容中的证据声明，包括统计数据、事实陈述和用户原声等。通过参考文档和网络资源进行验证，并生成详细的验证报告。

## 何时使用此技能

在以下情况下使用此技能：
- 用户要求验证文章、报告或内容蓝图中的证据
- 需要检查数据的准确性和来源可靠性
- 需要生成结构化的验证报告
- 用户提到"验证证据"、"fact-checking"、"证据验证"等关键词

## 核心工作流程

### 1. 证据识别

从目标文档中提取所有需要验证的证据声明，按以下类型分类：

**统计数据（Statistics）**：
- 数值数据（如月活用户数、增长率、占比等）
- 时间相关数据（如"截至2026年3月"等）
- 比较数据（如"环比增长X%"等）

**事实陈述（Facts）**：
- 描述性事实（如用户画像、平台特点等）
- 因果关系陈述（如"因为X，所以Y"等）
- 趋势描述（如"持续增长"、"逐渐下降"等）

**用户原声（Quotes）**：
- 直接引用的用户评论或反馈
- 用户调研中的原话
- 社交媒体上的用户发言

**参考链接（References）**：
- 文档中引用的所有外部链接
- 需要验证链接的有效性和内容与文档描述是否匹配

### 2. 验证流程

按照以下优先级进行验证：

**优先级1：参考文档**
- 首先使用用户提供的参考文档进行验证
- 检查文档中是否有直接支持证据的内容
- 记录参考文档中的具体位置（如行号、章节等）

**优先级2：官方来源**
- 使用WebFetch工具访问参考链接
- 验证链接的有效性和内容准确性
- 记录验证结果和任何差异

**优先级3：权威媒体**
- 如果参考链接失败，搜索权威媒体网站
- 优先使用政府网站、知名新闻媒体、行业报告等
- 验证数据的一致性和时效性

**优先级4：其他来源**
- 使用WebSearch工具搜索相关信息
- 交叉验证多个来源的数据
- 记录数据差异和可能的原因

### 4. 常见问题处理

**问题1：参考链接无法访问**
- 尝试使用WebSearch搜索相同内容
- 检查链接格式是否正确（如http/https、URL编码等）
- 如果链接重定向，使用重定向后的URL重试

**问题2：数据在参考文档中找不到直接支持**
- 检查是否间接支持（如通过推理或上下文）
- 标记为"⚠️ 需补充来源"
- 建议用户提供更直接的来源或修改为间接描述

**问题3：不同来源的数据有差异**
- 记录所有来源的数据和差异
- 优先使用权威来源（官方报告、政府网站等）
- 在报告中说明差异和可能的原因

**问题4：验证过程耗时较长**
- 优先验证关键证据（如核心数据、主要结论等）
- 对于次要证据，可以适当简化验证流程
- 在报告中说明验证的完整性和置信度

## 使用技巧

1. **系统性验证**：按照证据类型逐个验证，避免遗漏
2. **记录详细**：在验证报告中记录所有验证步骤和结果
3. **优先级明确**：优先验证关键证据和核心数据
4. **交叉验证**：使用多个来源验证重要数据
5. **及时沟通**：如果发现重大问题，及时与用户沟通

## 限制和注意事项

1. **网络访问限制**：WebFetch工具可能无法访问某些网站（如需要登录的网站）
2. **数据时效性**：注意数据的发布时间，优先使用最新数据
3. **来源可靠性**：评估来源的可信度，优先使用权威来源
4. **验证完整性**：根据时间限制和用户需求，平衡验证的完整性和效率
